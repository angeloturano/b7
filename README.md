# Pittsburgh Bachelor Trip — Clean Black & Gold Version

This version uses the Ben photo only in the hero header. The itinerary below uses the cleaner card layout.

## Deploy

1. Unzip this project.
2. Replace the files in your GitHub repository with these files.
3. Commit the changes.
4. Vercel will redeploy automatically.

## Edit itinerary text

Open `app/page.js` and edit the `days` array near the top.

## Replace the hero image

Replace `public/ben-hero.png` with a new image using the same filename.
